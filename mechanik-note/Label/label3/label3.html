LM Studio

요즘 독일에 살면서 매우 불편함을 한 가지 느낀다. 인터넷!!!! 한국에서는 어디를 가든 와아파 이가 가능하지만 독일은 지역과 장소에 따라 인터넷과 통신이 잘되지 않는다, 그래서 고민을 하던 중에 이번 주에 Chat GPT-5와 함께 GPT OSS도 공개가 되어서 사용을 해보았는데 꽤 괜찮아서 소개를 해보려고 한다.

GPT OSS 지금 현재 나의 불편함을 완벽하게 해결할 수 있는 AI 모델이다. Chat GPT를 로컬에서 사용할 수 있게 2가지 모델로 20b와 120b로 출시를 했다. 오프라인으로 내가 어디서든 사용할 수 있으니 엄청나게 좋지 않은가?

GPT OSS란?

GPT OSS는 OpenAI GPT 모델과 유사한 아키텍처를 가진, 공개(Open Source)로 배포되는 대형 언어 모델(Large Language Model)을 말한다.
OpenAI GPT 모델은 폐쇄적으로 운영되지만, GPT OSS는 누구나 소스코드를 보고, 수정하고, 직접 학습시키거나 사용 가능하다. 대표적으로 EleutherAI의 GPT-NeoX, GPT-J, GPT-Neo 등이 공개되어 있다.

GPT OSS 20B, 120B 모델이란?

20B, 120B는 모델 파라미터 수(즉, 학습된 가중치의 개수)를 의미한다. B는 Billion(십억)의 약자로, 20B는 200억 개 파라미터, 120B는 1200억 개 파라미터 모델을 지니고 있음을 뜻한다. 그래서 파라미터가 많을수록 모델의 표현력과 언어 이해 및 생성 능력이 일반적으로 더 뛰어나다.

20B Model

120 숫자 보다는 작아서 베타나 간단한 모델처럼 보일 수 있으나 약 20억 파라미터 이상의 대형 모델이다.
대표적인 20B급 OSS 모델로는 GPT-J 6B (6B지만 OSS 중에서는 성능 좋음), GPT-NeoX 20B ( EleutherAI에서 개발한 GPT-NeoX 기반 20B 모델)이 있다. 간단하게 말하자면 GPT-3 중간급 정도 수준으로 충분히 강력한 텍스트 생성, 질문 답변, 문서 요약 등 가능하다.

120B Model

1200억 개 파라미터로 초대형 모델에 속한다. 이게 어느 정도의 규모인지를 예를 들어 보자면 최근에 Meta AI의 LLaMA 2 70B가 공개되었고, 이를 파라미터로 환산하면 65~70B 정도이다. 또한 120B급 모델은 주로 OpenAI GPT-3 DaVinci (175B)나 Anthropic Claude, Google PaLM (540B) 같은 상용 모델에 있다.
그래서 사람에 가까운 자연어 이해 및 생성 능력, 다중 작업과 복잡한 추론, 창의적 생성 그러니 모든 방면에서 뛰어나다.

그러면 이를 어떻게 사용을 하는가? 나도 이거 디버깅 하고 사용자를 위한 프로그램이나 환경을 세팅할 시간은 없다… 그러니 이미 시중에 출시된 프로그램을 사용할 것이다.

LM Studio와 Ollama로 크게 2가지 프로그램이 있는데 현재 나는 Ubuntu OS를 사용하고 있고 대화만 간으하면 되기에 LM Studio를 사용할 것이다. Ubuntu에서는 Ollama의 인터페이스를 따로 구현해야 하기에 LM Studio를 사용하지만 Windows나 Mac 사용하는 분들은 Ollama 사용하는 것도 추천하다.

방법은 간단하다.

들어가서 그냥 다운만 하면 끝이다~

이미 인터페이스가 구현이 다 되어있으며 들어가면 자동으로 20b를 설치하는 과정을 진행해 주기에 간단하게 설치하고 바로 이용이 가능하다. 120b 경우에는 대규모 클러스터 혹은 데이터센터급 하드웨어가 필요로 하기에 포기하는 것을 권유한다. 뭐… 해보겠다면 여러분의 컴퓨터가 폴발하는 것을 눈 앞에서 확인할 수 있을 것이다. (수리 20에 해드립니다 ㅎㅎ)
기본적으로 간단한 코딩이나 문서 작업을 주로 하면서 주로 Chat GPT-3을 사용하는 나에게는 적당하다.
기본적으로 5GB의 내장메모리와 16GB 정도의 RAM이 필요하고 만약 내장 GPU를 사용한다면 CPU 라도 Intel I7 이상이기를 권장한다.

테스트를 진행해 봤는데 속도는 약간 한 박자 느린 정도이고 답변은 기본적으로 잘 나온다.

개인적으로 로컬로 작업하면 내 개인정보와 민감한 데이터도 마음껏 GPT에 사용할 수도 있고 공간에 제약을 받지 않는다는 점 만으로도 만족한다. 또한 파일 형식도 지원하고 대화 내용도 전부 로컬에서 관리도 가능하다.

추가 적으로 다른 OSS 모델도 다운해서 사용이 가능하기 자신에게 맞는 모델을 찾아 사용하는 것도 좋을 것 같다.
